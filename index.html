Documentación de la API

Obtén el reproductor de TONPlayer en segundos mediante URLs de embed simples

URL Base

api.tonplayer.space

Obtiene el reproductor de TONPlayer utilizando el ID de TMDB de una película.

GET https://api.tonplayer.space/play/movie/{tmdb_id}

Ejemplo

https://api.tonplayer.space/play/movie/550

Respuesta

<iframe src="https://api.tonplayer.space/play/movie/550" frameborder="0" allowfullscreen></iframe>

Obtiene el reproductor de TONPlayer con selector interno de temporadas y episodios.

GET https://api.tonplayer.space/play/tv/{tmdb_id}

Ejemplo

https://api.tonplayer.space/play/tv/1399

Respuesta

<iframe src="https://api.tonplayer.space/play/tv/1399" frameborder="0" allowfullscreen></iframe>

Obtiene el reproductor de TONPlayer directamente en una temporada y episodio concretos.

GET https://api.tonplayer.space/play/tv/{tmdb_id}/{temporada}/{episodio}

Ejemplo

https://api.tonplayer.space/play/tv/1399/1/1

Respuesta

<iframe src="https://api.tonplayer.space/play/tv/1399/1/1" frameborder="0" allowfullscreen></iframe>

Compatible con IDs de IMDb

Además de los IDs de TMDB, TONPlayer también acepta directamente IDs de IMDb (con el prefijo tt) en los mismos endpoints. No es necesario indicar de qué fuente proviene el ID: la API lo detecta automáticamente según su formato.

Ejemplo con ID de TMDB

https://api.tonplayer.space/play/movie/550

Ejemplo equivalente con ID de IMDb

https://api.tonplayer.space/play/movie/tt0137523
